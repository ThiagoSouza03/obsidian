# Carabina Blaster

**Custo:** 900 créditos (850 créditos sem coronha retrátil)
**Peso:** 2,2 kg
**Disponibilidade:** Restrita
**Dano:** 3d8
**Tipo de Dano:** Energia
**CD para Danificar/Crítico:** — (não especificado no livro-fonte para este tipo de arma)
**Alcance:** Rifles — Queima-roupa 0-30, Curto 31-60, Médio 61-150, Longo 151-300 quadrados
**Modo Automático:** Não
**Categoria de Proficiência:** Rifles

## Descrição
Este pequeno rifle blaster tem um cano curto e um cabo para duas mãos, fazendo-a parecer mais como uma pistola mais pesada do que com um rifle. Algumas carabinas blaster, como a E-11 usada por stormtroopers, possuem uma coronha retrátil (ver Coronhas Retráteis, página 130). Uma carabina blaster sem uma coronha retrátil custa 850 créditos ao invés de 900 créditos. Uma carabina blaster requer uma pilha de energia para funcionar. Depois de 100 disparos, a pilha de energia deve ser substituída.
