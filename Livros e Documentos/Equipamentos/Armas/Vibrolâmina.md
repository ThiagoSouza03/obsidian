# Vibrolâmina

**Custo:** 250 créditos
**Peso:** 1,80 kg
**Disponibilidade:** Licenciada
**Dano:** 2d6
**Tipo de Dano:** Cortante ou perfurante
**CD para Danificar/Crítico:** — (não especificado no livro-fonte para este tipo de arma)
**Alcance:** Corpo a corpo (sem incremento de alcance)
**Modo Automático:** Não
**Categoria de Proficiência:** Armas de Ataque Físico Avançadas

## Descrição
Uma vibrolâmina é uma arma de combate corpo a corpo preferida por mercenários através da galáxia. Ela lembra uma espada curta com uma aparência de alta tecnologia. Uma vibrolâmina requer uma célula de energia para funcionar.
