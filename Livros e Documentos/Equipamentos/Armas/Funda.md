# Funda

**Custo:** 35 créditos
**Peso:** 0,3 kg
**Disponibilidade:** —
**Dano:** 1d4
**Tipo de Dano:** Concussão
**CD para Danificar/Crítico:** — (não especificado no livro-fonte para este tipo de arma)
**Alcance:** Arma de Arremesso — Queima-roupa 0-6, Curto 7-8, Médio 9-10, Longo 11-12 quadrados
**Modo Automático:** Não
**Categoria de Proficiência:** Armas Simples

## Descrição
Uma arma primitiva, a funda lança balas ou pedras. O modificador de Vigor do usuário se aplica ao dano causado com uma funda.
