# Bowcaster

**Custo:** 1.500 créditos
**Peso:** 8 kg
**Disponibilidade:** Licenciada, Rara
**Dano:** 3d10
**Tipo de Dano:** Energia e perfurante
**CD para Danificar/Crítico:** — (não especificado no livro-fonte para este tipo de arma)
**Alcance:** Rifles — Queima-roupa 0-30, Curto 31-60, Médio 61-150, Longo 151-300 quadrados
**Modo Automático:** Não
**Categoria de Proficiência:** Armas Exóticas

## Descrição
O bowcaster é construído pelos Wookiees de Kashyyyk. Uma fusão de tecnologias antigas e modernas, muito parecido com uma metralhadora arcaica, embora o bowcaster seja tratado como se fossem estruturas de energia explosiva e velocidade gratória. Bowcasters são tratados como arma exótica, a menos que os seus proprietários sejam Wookiees, para os quais os bowcasters são tratados como rifles comuns. Um canhão blaster custa 50 créditos para determinar o dano ou alcance de outra maneira. Uma aljava de 10 dardos custa 50 créditos.
