# Rifle Blaster Esportivo

**Custo:** 800 créditos
**Peso:** 4 kg
**Disponibilidade:** Licenciada
**Dano:** 3d6
**Tipo de Dano:** Energia
**CD para Danificar/Crítico:** — (não especificado no livro-fonte para este tipo de arma)
**Alcance:** Rifles — Queima-roupa 0-30, Curto 31-60, Médio 61-150, Longo 151-300 quadrados
**Modo Automático:** Não
**Categoria de Proficiência:** Rifles

## Descrição
Os rifles blaster esportivos são populares entre tanto quanto entre a elite galáctica quanto entre colônias isoladas. Rifles blaster especiais devem ser obtidas para porta-vozes do sistema SAAMF, ou Sistema de Aquisição de Armas Centrais, e permissões especiais com armas neles. Um rifle blaster esportivo requer uma pilha de energia para funcionar. Depois de 100 disparos, a pilha de energia deve ser substituída.
