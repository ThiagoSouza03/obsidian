# Kit de Cirurgia

**Categoria:** Equipamento Médico
**Custo:** 1.000 créditos
**Peso:** 10 kg
**Disponibilidade:** —

## Descrição
Este pequeno kit do tamanho de uma pasta de documentos contém quase tudo que um personagem precisa para salvar uma vida: analisadores de diagnóstico, antídotos para envenenamento, medicina para radiação, entre outras ferramentas cirúrgicas e suprimentos limitados. Um kit de cirurgia possui seis usos, cada um com uma carga de até 150 kg de carga, e é essencialmente utilizado para tratar Ferimento.
