# Cartão de Dados

**Categoria:** Computadores e Dispositivos de Armazenamento
**Custo:** 10 créditos (pacote de 10)
**Peso:** 0,1 kg
**Disponibilidade:** —

## Descrição
Um cartão de dados é um pequeno dispositivo de armazenamento que consiste de uma fita de dados na memória do computador. Alguns dispositivos de armazenamento de dados usam cartões de dados; outros utilizam chips ou cilindros como o chip de crédito e o cilindro de códigos.
