# Poder Acelerado

Quando usar um poder da Força que requer uma ação padrão para ativar, você pode gastar um Ponto de Força para ativar o poder como uma ação rápida. Alternativamente, você pode gastar um Ponto de Destino para ativar o poder como uma ação livre.
